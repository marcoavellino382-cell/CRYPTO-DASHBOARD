# Crypto Pulse — Real-Time Cryptocurrency Dashboard

**Crypto Pulse** is a modern, responsive web application that tracks real-time cryptocurrency prices in Euro (€) using the public CoinGecko API. Built with a clean dark-mode interface, it provides instant market updates without requiring external frameworks or backend dependencies.

## Features

- **Live Market Data:** Displays real-time prices in EUR for major cryptocurrencies (Bitcoin, Ethereum, Solana, Cardano).
- **24h Performance Tracking:** Highlights 24-hour percentage changes with color-coded visual indicators (green for gains, red for losses).
- **Manual & Automatic Refresh:** Includes an instant refresh button alongside automatic updates and a timestamp showing the latest sync.
- **Responsive Dark UI:** Designed with a sleek, mobile-first dark theme that adapts seamlessly across desktop, tablet, and smartphone screens.
- **Zero-Dependency Architecture:** Lightweight single-file structure (`index.html`) combining semantic HTML5, modern CSS3, and vanilla JavaScript.

## Tech Stack

- **HTML5:** Semantic structure and accessible layout.
- **CSS3:** Custom dark-mode styling, CSS Grid/Flexbox, and responsive breakpoints.
- **JavaScript (ES6+):** Asynchronous `fetch` API calls, DOM manipulation, and error handling.
- **CoinGecko API:** Free public REST API for live cryptocurrency market data.
- **GitHub Copilot:** Used during development for code generation, UI refinement, and automated responsive testing.
